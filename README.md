## What's in this repo

Two field tests on live products, carried out as part of the 
Webbo3 Academy Software Testing programme.

### 1. CampusKart — Student Marketplace

A live marketplace for Adekunle Ajasin University, Akungba.

- **Test plan** — scope, environment matrix, entry and exit 
  criteria, risks.
- **Test case file** — 80 manual test cases across 10 modules.
  42 positive, 20 negative, 18 edge cases. Fully executed on 
  HP EliteBook (Windows 11) and Redmi Note 13 (Android).
- **Defect log** — 10 bugs filed with severity, priority, 
  reproducibility and evidence.
- **Evidence pack** — annotated screenshots for every bug.
- **Test summary report** — pass/fail/blocked counts, risk 
  analysis, release verdict.

Highlight: **BUG-001 (Critical)** — after logout, the browser 
Back button returns the user to the previously authenticated 
page. The session is not cleared on logout.

### 2. PayLow — Live Nigerian Fintech App

A live finance app that moves real money.

- **Bug report** — single defect write-up in the field order 
  the assignment specified.

Highlight: **BUG-PL-003 (Critical)** — the Change PIN screen 
accepts a wrong current PIN without any error and proceeds to 
change the PIN.
